## 1. Assignment Overview:

The assignment is intentionally simple. The purpose is to evaluate how quickly you can understand what our company does, given the fact that the technology running the company is niche, and how effectively you can build on top of that understanding.

We want to see whether you can think simply and actually get things done like an engineer equivalent to an early-career SDE-1. You will be given resources that explain what NComputing India solves. Your task is to understand the pain points we address, identify the customers we are targeting, and build both a marketing website and a small product workflow around one of our solutions.

---

## 2. What you must do

We have attached some resources that include two videos explaining what NComputing does, along with our official website. Watch the videos, explore the website, and build a reasonable understanding of what we do.

Out of all the products that we offer, choose any one product and use any tool you need to understand what problem it solves. You do not need to go extremely deep, but your understanding should be relevant enough to build a meaningful solution around it.

Please also explain why you chose that particular product. Your reason can be as simple as:

> "This product was the easiest for me to understand."
> 

Identify the target audience for your chosen product and use that understanding to design both the technical implementation and the visual experience.

---

## 3. Website

Build a 2–3 page website that communicates the product clearly.

A suggested structure is:

- Landing Page
- Problem Page
- Solution Page
- Product Page

You are free to change this structure by adding, removing, or combining pages if you believe it creates a better user journey. Please briefly explain your reasoning.

The purpose of the website is to take the user from:

- understanding what NComputing broadly does,
- understanding the problem they are facing,
- understanding how the product you selected solves that problem.

---

## 4. Ordering Portal

In addition to the marketing website, build a simple ordering portal for the product that you selected.

A user should be able to:

- View the product.
- Select quantity (and any reasonable configuration options if applicable).
- Add the product to a cart.
- Proceed through checkout.
- Enter shipping and billing information.
- Complete a payment using a sandbox payment gateway (Stripe, Razorpay, or any equivalent service).
- Receive an order confirmation email once the purchase is completed.

The objective is not to build a production-ready e-commerce platform, but to demonstrate that you can own a complete user workflow from frontend to backend.

---

## 5. Admin Dashboard

Build a simple internal dashboard that allows an administrator to:

- View all incoming orders.
- Search or filter orders.
- Update the order status (for example: Pending, Processing, Shipped, Delivered).
- View basic order information such as customer details, purchased products, and payment status.

---

## 6. Lead Capture

Not every customer is ready to purchase immediately.

Provide a simple way for users to:

- Request a demo.
- Contact Sales.
- Request pricing.

Store these submissions in your database so they can be viewed from the admin dashboard or another appropriate interface.

---

## 7. Deployment

Deploy the complete project so that it is publicly accessible.

You are free to use any hosting platform such as Vercel, Netlify, Railway, Render, or any equivalent service.

Please submit both the deployed URL and the source code repository.

---

## 8. Code Quality & Design

We are not looking for pixel-perfect UI.

Instead, we are looking for thoughtful engineering.

Your solution should demonstrate:

- Clean and maintainable code.
- Reusable components where appropriate.
- Consistent spacing, typography, and design decisions.
- A responsive experience that works well across desktop and mobile devices.
