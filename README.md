# NComputing L-Series — SDE Intern Assignment

A full-stack web project showcasing the NComputing L-Series thin client product.

## What it includes

- **Marketing site** — Landing, Problem, Solution, Product pages
- **Ordering portal** — Cart, Checkout (Razorpay), Order Confirmation
- **Admin dashboard** — Orders + Leads management
- **Lead capture** — Demo / Contact Sales / Pricing request modal

## Stack

- **Frontend**: React + Vite + Tailwind CSS + Zustand
- **Backend**: Node.js + Express + Prisma
- **Database**: PostgreSQL (Neon)
- **Payments**: Razorpay (test mode)
- **Email**: Nodemailer (Gmail)
- **Deploy**: Vercel (frontend) + Render (backend)

## Product

**NComputing L-Series** (L250 / L300 / L350) — thin client devices that let one server PC serve up to 100 virtual desktops simultaneously, at 3–5W per device.

Target: Schools, SMBs, BPOs, and government offices in India.
